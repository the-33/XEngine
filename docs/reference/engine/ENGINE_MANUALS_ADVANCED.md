The current benchmark workflow and instrumentation are relevant to engine
development. Dated optimization experiments (v8–v16.19), migration proposals
and calibration reports remain available in the repository as **archive**;
they are excluded from the generated API reference because their intermediate
measurements and experimental defaults do not define today's engine behavior.
