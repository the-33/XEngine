# Manuals and current guides {#xengine_engine_manuals}

This section groups the **current** Markdown manuals. They are helpful when
developing or modifying XEngine, but should not overwhelm the class and module
index. Historical design notes are kept in the repository, outside this index.

- @subpage xengine_manual_game "Gameplay and public API manuals"
- @subpage xengine_manual_build "Toolchains, configuration and shipping"
- @subpage xengine_manual_advanced "Diagnostics and engine maintenance"

If you are building a game, follow the dedicated Game Developer Reference
first. Older benchmark reports and migration case studies describe specific
experiments and do not override current public API contracts.
